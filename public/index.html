Seedance 2.0 internal tool

兔狲视频生成器

这是火山方舟 Seedance 2.0 的内部测试与部署入口。核心代码已经保存到 GitHub，后端支持文生视频、图生视频、视频生视频、真人肖像 Asset 授权、TOS 外链上传、任务轮询、下载、费用估算和详细日志。

查看 GitHub 仓库 部署说明

当前上线状态

Cloudflare Pages 已作为公网入口发布。当前页面是安全入口页，不包含火山方舟或 TOS 密钥。真正的视频生成后端需要运行在服务器上，再通过 Cloudflare Tunnel 或反向代理接入。

推荐部署结构

  • GitHub 保存核心代码和 Docker 部署文件。
  • 服务器运行 Python 后端和持久输出目录。
  • Cloudflare 负责域名、HTTPS、访问权限和公网入口。
  • 密钥只放服务器环境变量，不写入前端、不提交 GitHub。

服务器启动命令

在服务器填写 .env.seedance-web 后运行 docker compose -f docker-compose.seedance-web.yml up -d --build。
